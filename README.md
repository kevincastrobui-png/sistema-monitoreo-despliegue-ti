 Sistema web para el monitoreo y control de despliegue de equipos de TI

Proyecto académico de Ingeniería de Sistemas.

## Objetivo

Desarrollar un sistema web para el registro, consulta y análisis
de equipos de TI desplegados.

## Funcionalidades

- Registro de equipos
- Consulta histórica
- Búsqueda y filtros
- Control administrativo
- Exportación de información
- Visualización de indicadores
- Gráficas por estado y modelo

## Tecnologías

- HTML
- CSS
- JavaScript
- Chart.js

## Estado del proyecto

Prototipo funcional en evolución hacia una arquitectura web
con almacenamiento centralizado.
